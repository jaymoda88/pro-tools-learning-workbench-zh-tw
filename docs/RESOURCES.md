# 學習資源資料與路線

`content/resources.json` 由使用者提供的四份 Pro Tools 學習資源筆記整理。原始清單記錄日期為 **2026-11-01**，共 124 筆條目；Avid Learning Partner 名錄在兩份清單重複出現，依主要網址合併後為 **123 筆獨立資源**，原始來源記錄均保留。

## 資料範圍

| 資料 | 用途 |
|---|---|
| 資源標題、提供者、主要與延伸網址 | 連回提供者查閱文件、課程、影片或素材。 |
| 語言、媒體類型、程度、費用類型 | 支援依條件篩選；費用以免費、付費、部分免費／試用、待確認分類。 |
| 版本／發布資訊 | 保留原蒐集筆記的快照資訊；不視為自動更新的相容性或開班保證。 |
| verification | 分開保存原清單的開啟確認、有限確認、未驗證及失效狀態。 |
| sourceRefs／provenance | 追溯原始筆記標題、檔案及文字雜湊；不包含本機路徑。 |
| relatedNoteIds | 連到工作台中可搭配閱讀的概念分篇，並不宣稱外部資源逐節對應原書。 |
| rights／rightsScope | 保留素材使用條款的原清單摘要，並連回提供者；實際使用前仍應讀現行條款。 |

**驗證欄的來源是使用者提供的研究筆記。** 這次資料轉換沒有逐一觀看影片、試用課程、重新查價或審核全部素材授權；`liveAvailabilityChecked` 明確保留為 `false`。遇到網站限制、搜尋摘要或僅確認 PDF 標頭等情況，保留其原始限制，不以「有效連結」替代內容品質判斷。

全站使用這批資源的官方／原作者連結。原資料夾的 PDF、影片、音訊與付費內容未複製到 repo，所有檔案也不由網站代為下載。

## 六條實作路線

| 路線 | 完成目標 |
|---|---|
| 第一個 Session | 確認 Engine、I/O、錄放、備份及可重開的工程。 |
| 人聲與 Comping | 保留 Take、整理接縫、Clip Gain 與音準處理，留下可回頭修改的版本。 |
| 多軌鼓編輯 | 設定編輯尺度、理解 Beat Detective、檢查 Crossfade 與自然感。 |
| 對白與影視後製 | 對齊畫面時間、定位、對白電平與交付資訊。 |
| Atmos 基礎 | 核對自身版本／方案條件，理解 Bed、Object、Renderer 與交換。 |
| Mixdown 與交付 | 先選真正適用的規範，再記錄量測方法、檔案格式與版本。 |

每條路線由短步驟組成，步驟包含既有教學分篇、外部補充資源與可檢查的實作成果。路線選用免費入口；素材仍依各提供者的條款使用。既有分篇以 2023.3 為來源，新版內容的適用性另外由版本資訊說明，不能只因連上新版官方文件就宣稱全文已更新。

## 維護

新增或修正條目時，保留穩定 ID、原始驗證範圍與研究日期。主要網址相同的條目合併來源記錄。`scripts/build_resources.py` 的 `load_catalogue()` 只讀取 JSON 並檢查資料關係，不會自動擷取網站、執行外部內容或下載檔案。

建置端可讀取 `resources`、`learningPaths`，並將 `researchDate`、數量與 `provenance` 保存在 `resourceMeta`。資源檢查涵蓋重複網址、HTTP(S) 協定、參考筆記、路線步驟與來源範圍，也拒絕本機路徑與數字價目混入公開資料。
