# 第三方元件

所有執行期元件都在本機打包，網站不需要從 CDN 載入程式。

| 元件 | 版本 | 用途 | 授權 |
|---|---|---|---|
| markdown2 | 2.5.5 | 建置時轉換文章 Markdown | MIT；scripts/vendor/MARKDOWN2-LICENSE.txt |
| Mermaid | 10.9.3 | 瀏覽器繪製圖表 | MIT；dist/vendor/MERMAID-LICENSE.txt |
| KaTeX | 0.16.22 | 瀏覽器渲染數學公式 | MIT；dist/vendor/KATEX-LICENSE.txt（字型授權見上游 package） |

來源：https://pypi.org/project/markdown2/ 、https://github.com/mermaid-js/mermaid 、https://github.com/KaTeX/KaTeX 。
