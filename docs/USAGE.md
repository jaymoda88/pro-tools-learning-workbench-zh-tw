# 使用指南

## 選擇並開啟工作台

到 [最新 Release](https://github.com/jaymoda88/pro-tools-learning-workbench-zh-tw/releases/latest) 的 Assets 下載 HTML 或 ZIP。

| 格式 | 開啟方式 | 保存與移動 |
|---|---|---|
| 單檔 HTML | 下載後用支援 JavaScript 的瀏覽器開啟。 | 保存這個 HTML 即包含內建教材、圖片、字型與互動套件。 |
| 資料夾 ZIP | 完整解壓後，開啟資料夾內的 `index.html`。 | 請將整個資料夾一起移動；單獨拿走 `index.html` 會缺少資料、圖片與套件。 |

內建教材、搜尋與練習可離線使用。外部影片、課程、素材下載與官方 PDF 仍需要網路；資源目錄中的連結不代表外站內容也包含在包內。

手機的檔案預覽程式可能限制 JavaScript。若只有靜態畫面或操作無反應，請改用瀏覽器開啟；各種 iOS Files／Quick Look 預覽並未全部實機驗收。

## 找到要學的內容

| 入口 | 使用方法 |
|---|---|
| 首頁任務 | 選擇錄音、剪輯、混音、交付或故障排查等需求，再進入相關篇章。 |
| 全站搜尋 | 輸入中文問題或英文功能，例如「修音 人聲」或 `Track Pinning`；結果包含筆記、索引、資源與版本功能。 |
| 主題探索 | 依系統設定、Session、錄音、編輯、MIDI、聲音處理、混音或空間音訊縮小範圍。 |
| 功能與術語索引 | 回查功能目錄、術語、原文疑義與實作指南。 |
| 學習資源 | 組合語言、類型、費用、程度與主題篩選，開啟資源卡查看條件與原始連結。 |
| 學習路線 | 從學習資源頁選路線，依步驟閱讀與練習；完成實作檢核後標記進度。 |
| 版本差異 | 按版本或工作主題篩選。先看適用方案與限制，再沿連結補足基礎觀念。 |
| 互動工具 | 點選訊號路由的節點，或比較 Commit、Freeze、Bounce 的用途。 |

閱讀頁提供篇內目錄與字級調整；章節教學可收藏及標記已讀。桌面使用側欄導覽，手機可從頂端選單找到完整入口，底部保留常用導覽。

## 查詢與練習 Mac 快捷鍵

在「Mac 快捷鍵」使用情境、文字與虛擬鍵盤篩選。表格同時保留按鍵、必要條件與來源頁碼；複製按鍵不會執行 Pro Tools 指令。

「快捷鍵練習」可選翻卡或測驗，並將需要再練的題目保留在待複習題庫。

| 題庫 | 文件範圍 |
|---|---|
| 2023.3 | 原有 135 筆 Mac 快捷鍵。 |
| 2026.4 | 已對照新版文件的 35 筆子集；其餘 100 筆未標成新版已驗證。 |

兩個版本分別記錄熟悉與待複習狀態。按鍵是否生效仍取決於 Pro Tools 的視窗焦點、Commands Keyboard Focus、Numeric Keypad Mode 及自訂設定；文件核對不等於逐鍵實機測試。不可 Undo 的操作會另外提醒，請先用練習 Session 確認。

網站本身提供以下導覽按鍵，與 Pro Tools 的操作分開：

| 網站按鍵 | 功能 |
|---|---|
| `⌘K`／`Ctrl K` | 移到全站搜尋欄。 |
| `/` | 未在輸入文字時，移到搜尋欄。 |
| `?` | 未在輸入文字時，開啟網站操作說明。 |
| `Esc` | 可關閉手機導覽；對話框依瀏覽器的標準操作關閉。 |

## 保存與接續進度

收藏、已讀、最近閱讀、路線檢核、快捷鍵練習與顯示偏好保存在目前瀏覽器，沒有帳號或 GitHub 自動同步。

1. 在側欄開啟「學習資料與設定」。
2. 選「匯出學習紀錄」，保存下載的 JSON。
3. 在另一台裝置或另一份工作台開啟相同設定，選「匯入紀錄」。
4. 匯入會合併現有紀錄，不會清空既有收藏與進度。

不同瀏覽器、私密模式、HTML 檔案位置或 HTML／ZIP 格式可能使用不同儲存空間。清除網站資料、移動檔案或換裝置前先匯出；若瀏覽器拒絕儲存，工作台會提示本次紀錄僅暫存，請另存備份。

## 開啟或顯示問題

| 狀況 | 處理方式 |
|---|---|
| ZIP 解壓後缺少內容或圖解 | 確認使用完整資料夾，沒有只移動 `index.html`；必要時重新下載並完整解壓。 |
| 手機預覽沒有互動 | 改用支援 JavaScript 的瀏覽器；詳細限制見 [單檔版說明](SINGLE-FILE.md)。 |
| 圖表或公式無法顯示 | 先重新開啟；圖表會保留原始碼供閱讀。多檔版也可用下方本機伺服器方式重試。 |
| 官方來源或課程連結無法開啟 | 確認網路，回來源網站查找；外站內容與可用性由原站維護。 |
| 切換版本後找不到收藏 | 回舊檔案／瀏覽器匯出，再到新版本匯入。 |

若電腦已安裝 Python 3，可在解壓後含 `index.html` 的資料夾執行：

```sh
python3 -m http.server 4173 --bind 127.0.0.1
```

用瀏覽器開啟 `http://127.0.0.1:4173`，使用完在終端機按 `Ctrl+C` 停止。這是多檔版遇到本機檔案限制時的選項，單檔版一般可直接開啟。

仍有問題時，請到 [Issues](https://github.com/jaymoda88/pro-tools-learning-workbench-zh-tw/issues) 附上工作台版本、HTML／ZIP 格式、作業系統、瀏覽器與重現步驟。下載驗證及實機驗收範圍見 [驗證紀錄](VERIFICATION.md)。
