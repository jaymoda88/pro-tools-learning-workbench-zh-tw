## 尚待擁有者處理的既有公開副本

目前分支移除檔案，不會清除 Git 歷史。兩份 PDF 仍可能透過先前 commit／tag 取得；已唯讀檢查 `v1.0.0` 的 `pro-tools-workbench.zip`，確認含兩份來源 PDF。該 Release 已轉為草稿以暫停公開下載，附件本身保留，尚未刪除。新版 Release 不會包含原廠 PDF。

可另外採取的具體動作：刪除舊 Release 的含 PDF 附件；若要移除歷史檔案，需改寫分支與受影響的 tags，再強制更新遠端。這些動作不包含在一般可逆程式修正中，也無法保證刪除已被他人下載或 fork 的副本。
