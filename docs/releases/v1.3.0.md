## Pro Tools 工作台 v1.3.0

這版把教學、外部資源、新版差異與操作練習放進同一個工作台，讓閱讀可以接到自己的 Session 實作。

**整理與製作：許惟傑 Xue_hwcxx · [@jaymoda88](https://github.com/jaymoda88)**

### 下載與開啟

在下方 Assets 下載 **pro-tools-workbench-v1.3.0.zip**，解壓後開啟 **index.html**。教學、搜尋、練習及圖解已包含於網站包；影片、課程與官方 PDF 需連線查閱。若瀏覽器限制本機圖表，可在解壓資料夾執行 `python3 -m http.server 4173`，再開啟 `http://localhost:4173`。

### 本版新增

| 項目 | 內容 |
|---|---|
| 學習資源庫 | 124 筆來源整理合併為 123 筆資源，支援語言、類型、費用、程度與主題篩選。 |
| 實作路線 | 6 條路線、24 個檢核，連結教學、資源及動手確認；以穩定 step ID 保存進度。 |
| 版本差異 | 11 個版本節點、25 項導讀，附條件、練習及官方頁碼，涵蓋 2023.6 至 2026.4.1。 |
| 新版實作指南 | 新增 2026.4 錄音，以及混音／交付實作教學，明確標示來源版本。 |
| Mac 快捷鍵練習 | 翻卡、測驗與待複習，可在 2023.3 的 135 筆及 2026.4 已核對的 35 筆子集間選擇。 |
| 全站搜尋 | 可找筆記、索引、資源與版本功能，並直接開啟對應內容。 |
| 署名與來源 | 網頁／列印浮水印、文章署名、PNG 像素與 iTXt 標記、長文複製來源及 Release 逐檔指紋。 |

原有 122 篇教學與 135 筆快捷鍵仍以 **2023.3** 為基準。2026.4 快捷鍵只核對了 35 筆，其餘 100 筆尚未逐項確認；原文比對不代表 Pro Tools 實機測試。課程與影片的查核狀態沿用原資源整理紀錄，未逐一試看。

**SHA256SUMS.txt** 可核對整個 ZIP，包內 **PROVENANCE.json** 記錄其他檔案的 SHA-256。正式 Release workflow 透過 `actions/attest@v4` 建立簽署的建置來源；該次流程完成後可用：

```sh
gh attestation verify pro-tools-workbench-v1.3.0.zip \
  -R jaymoda88/pro-tools-learning-workbench-zh-tw
```

簽章用於核對建置來源，不證明所有權，也不防止複製。浮水印與 metadata 可以被移除；v1.2 等歷史版本的原圖仍曾公開。這版沒有把公開網站宣稱為加密或不可複製的內容。
