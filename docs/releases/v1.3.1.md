## Pro Tools 工作台 v1.3.1

v1.3.1 增加單檔 HTML 離線交付格式。保留既有 ZIP 多檔格式與教材內容，v1.3.0 Release 也不會覆蓋。

### 下載與開啟

Release 提供 **pro-tools-workbench-v1.3.1.html** 與 **pro-tools-workbench-v1.3.1.zip**。HTML 下載後直接用瀏覽器開啟，不需解壓；ZIP 解壓後開啟 `index.html`。手機檔案預覽程式可能限制 JavaScript，遇到搜尋或互動無法使用時，請改用瀏覽器開啟。iOS Files 與 Quick Look 的支援狀況不作全面保證。

單檔 HTML 內嵌本套完整筆記、資源目錄、66 張水印 PNG、搜尋互動、Mermaid、KaTeX、字型與第三方授權資訊，並以可展開區塊收錄 `LICENSE`、`NOTICE`、`CITATION`。影片、課程及 Avid 官方 PDF 仍為外部官方連結，離線時無法取得外站內容。

兩種格式可能因 `file://` 儲存來源不同而無法自動共用收藏、已讀、路線進度及練習紀錄。切換格式或裝置前，建議在舊版設定匯出學習紀錄 JSON，再於新版匯入。ZIP 多檔版仍按需載入內容並保留獨立 PNG；本版只增加發行格式，不改圖形樣式或內容版本。

### 發布附件與驗證

- `pro-tools-workbench-v1.3.1.html`
- `pro-tools-workbench-v1.3.1.zip`
- `SHA256SUMS.txt`：包含 HTML 與 ZIP 的 SHA-256。
- `provenance.sigstore.json`：簽署 HTML 與 ZIP 的發布來源。

單檔 HTML 實際為 **16.95 MB**，資料夾 ZIP 為 **7.71 MB**。[整合 CI 已通過](https://github.com/jaymoda88/pro-tools-learning-workbench-zh-tw/actions/runs/41311371095)：逐位元核對 66 張圖與 60 個字型、完整授權文字、file URL 路由、搜尋與練習，以及真正的 KaTeX DOM／Mermaid parser；單檔測試禁止網路資源載入。正式 HTML 與 ZIP 的來源簽章由發布流程建立；實際裝置排版、列印與 Mermaid SVG 視覺效果仍待驗收。ZIP 與單檔的使用限制及儲存差異詳見[單檔離線版說明](../SINGLE-FILE.md)。
