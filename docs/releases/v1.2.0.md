## Pro Tools 工作台 v1.2.0

這版修正內容導航、繁中搜尋與注音輸入，並把公開網站統一改為查閱 Avid 官方 PDF。

**整理與製作：許惟傑 Xue_hwcxx · [@jaymoda88](https://github.com/jaymoda88)**

### 使用方式

下載下方 Assets 的 **pro-tools-workbench-v1.2.0.zip**，解壓後開啟 **index.html**。網站含文章、搜尋、快捷鍵與原創圖解；來源 PDF 連結需網路連線。若瀏覽器限制本機圖表，可在解壓資料夾執行 `python3 -m http.server 4173`，再開啟 `http://localhost:4173`。**SHA256SUMS.txt** 可核對下載檔案。

### 更新

| 項目 | 行為 |
|---|---|
| 索引與勘誤 | 8 頁功能目錄、快速檢索、術語、原文疑義等可直接閱讀與搜尋。 |

| 注音輸入 | 選字中的 Enter 不會觸發搜尋或移走焦點。 |
| 圖表與主題 | Mermaid／KaTeX 按需載入；首次跟隨系統主題，切換時重繪圖表；失敗時保留說明與原始碼。 |
| 來源與封裝 | 目前分支與新版網站包排除原廠 PDF，改連 Avid 官方文件。 |
