## v1.1 手機與桌面介面

執行 `npm run check` 可重現資料、連結與 DOM fixture 檢查。fixture 是有限的 DOM 替身，不會計算 CSS、文字尺寸、捲動或真實觸控行為。

| 檢查 | 結果 |
|---|---|
| Node.js 語法 | 通過。 |
| 內容完整性 | 122 篇文章、66 章、135 筆快捷鍵、8 個主題。 |
| 連結存在性 | 226 個附件引用、574 個筆記連結通過；同一附件可多次引用。 |
| 路由 | 手機與桌面分支各開啟全部 122 篇文章；主題、工作流程、工具、收藏、搜尋、快捷鍵均能產生 HTML。 |
| 搜尋 | Clip Gain、沒有聲音、補錄、Freeze、Automation 有結果；不存在字串回傳空結果。 |
| 快捷鍵 | 135 筆皆產生功能、Mac 按鍵、必要條件、來源標籤；修飾鍵與字母辨識檢查通過。 |
| 閱讀狀態 | 收藏、已讀、最近閱讀、字級與 Dark mode 寫入儲存資料通過。 |
| 手機側欄 | 開啟後背景和底部導覽不可聚焦；Escape／背景遮罩關閉後還原焦點、⌘K 關閉側欄並進入搜尋的 fixture 檢查通過。 |
| 作者 | HTML metadata、頁尾作者連結與 README 署名一致，GitHub 連到 `jaymoda88`。 |
| CSS 程式審查 | 修正快捷鍵表格舊欄寬覆蓋、收藏按鈕觸控寬度、Dark mode 選取色，窄螢幕底部導覽間距，以及列印布局的跨檔覆蓋。 |
| 執行期依賴 | Mermaid、KaTeX 已本地打包，不依賴 CDN 下載程式。 |
