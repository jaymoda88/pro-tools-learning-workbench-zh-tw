# 設計依據

這個版本保留原書內容的章節關係，但將「使用者要完成的工作」放在最上層。它是獨立互動應用，不是換皮的長篇目錄。

## 參考的公開專案

- [Quartz](https://github.com/jackyzha0/quartz)：參考全文搜尋、知識連結與閱讀導覽的組合；不照搬以檔案樹為首的入口。
- [Material for MkDocs](https://github.com/squidfunk/mkdocs-material)：參考搜尋高亮、主題與頁內導覽，讓長文件可定位。
- [Dendron](https://github.com/dendronhq/dendron)：參考清楚的主題階層；本版用任務與主題名稱代替需要記憶的檔名階層。

## 內容策略

八大主題：設定與入門、Session 與素材、錄音、Audio 剪輯、MIDI 與編排、Processing、混音與交付、空間音訊與影像。跨章的工作流程引用同一批筆記，不重複維護文章。快捷鍵是結構化資料，可以按名稱、情境、modifier 與字母篩選。

## 視覺與互動

採清楚的工作站式分欄，以冷白、鋼藍與紫色建立層次；標示用於表達分類、選取與進度。文章內容保持適當行寬；工具頁保留操作密度。收藏、已讀、偏好存於當前瀏覽器，可用 JSON 匯出／匯入；不需要第三方登入，也不會上傳個人閱讀紀錄。
