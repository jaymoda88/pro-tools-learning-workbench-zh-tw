# Pro Tools 工作台

繁體中文 Pro Tools 互動學習工作台，涵蓋錄音、編輯、MIDI、混音與交付。可搜尋中文問題或英文功能名稱，查閱教學、Mac 快捷鍵、版本差異與學習資源；專業術語及功能名稱保留英文。

**整理與製作：許惟傑 Xue_hwcxx** · [GitHub @jaymoda88](https://github.com/jaymoda88)

## 內容與功能

| 內容 | 目前提供 |
|---|---|
| 教學與實作 | 66 章整理為 122 篇教學、66 張原創圖解，另有索引、術語、原文疑義及 2026.4 實作指南。 |
| Mac 快捷鍵 | 135 筆情境速查，搭配翻卡、測驗與待複習題庫。 |
| 學習資源 | 123 筆文件、影片、課程與素材，可依語言、類型、費用、程度及主題篩選。 |
| 學習路線 | 6 條路線、24 個實作檢核，串連教材與資源。 |
| 版本差異 | 11 個版本節點、25 項功能導讀，附適用條件與官方來源。 |
| 閱讀與檢索 | 全站搜尋、收藏、已讀紀錄、深淺色模式、閱讀字級與篇內目錄。 |

**教材版本：**基礎教學與 135 筆快捷鍵依 **Pro Tools 2023.3** 文件整理；新版補充另外標示來源。2026.4 題庫目前收錄 **35 筆經文件核對的按鍵**。來源依據與查核限制見 [內容與版本文件](docs/README.md#內容與權利)。

## 下載與開始使用

1. 前往 [最新 Release](https://github.com/jaymoda88/pro-tools-learning-workbench-zh-tw/releases/latest)，在 **Assets** 選擇一種格式。
2. 用瀏覽器開啟下載的 HTML，或解壓 ZIP 後開啟 `index.html`。
3. 從首頁任務開始，或按 **⌘K／Ctrl K** 搜尋問題與功能名稱。

| 格式 | 適合的使用方式 |
|---|---|
| **單檔 HTML** | 一個檔案即可攜帶；教材、圖解、字型與互動套件已內嵌，不需解壓。 |
| **資料夾 ZIP** | 解壓後使用，保留獨立圖片與網站檔案；請將整個資料夾一起保存。 |

兩種格式都可離線閱讀內含教材、搜尋及練習；**外部影片、課程與官方 PDF 需要網路**。手機請用支援 JavaScript 的瀏覽器開啟，檔案預覽程式可能無法執行互動功能。

## 使用入口

| 想做什麼 | 到哪裡找 |
|---|---|
| 從零開始，或完成錄音／混音任務 | 首頁任務、工作流程、學習路線 |
| 查觀念、功能或英文術語 | 全站搜尋、主題探索、功能與術語索引 |
| 查按鍵並練熟 | Mac 快捷鍵、快捷鍵練習 |
| 比對新功能與適用版本 | 版本差異、各篇來源說明 |
| 找課程、影片或練習素材 | 學習資源 |
| 保存與接續學習 | 我的收藏、已讀標記、學習資料與設定 |

學習紀錄儲存在目前瀏覽器，不會自動同步至 GitHub。換裝置或切換 HTML／ZIP 版本前，請在「學習資料與設定」**匯出學習紀錄**，再到另一份工作台匯入。

詳細操作、開啟問題與備份方式見 [使用指南](docs/USAGE.md)；格式差異見 [單檔離線版說明](docs/SINGLE-FILE.md)。
