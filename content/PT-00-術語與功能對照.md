# 術語與功能對照 — 用中文找到英文名稱

> 先把資料、Track、路徑、控制與時間分清楚，英文功能名稱就不再只是需要背下來的單字。

這是一份精選概念檢索表，**英文欄保留正式名稱，中文欄提供日常查找詞與解釋**。需要完整操作請沿連結進教學與原文；查按鍵則開 [[PT-00-Mac快捷鍵]]。用 `Cmd+F` 搜「回送」「凍結」「軌道」「工程檔」等詞即可查找。

|---|---|---|---|

| 素材檔、音訊影片檔 | **Media Files** | Session 使用的 Audio、MIDI、Video 相關資料；其中 Audio／Video 檔案與 .ptx 分開儲存。 | 原書 p. 11；[[Pro_Tools_Reference_Guide_2023.3.pdf#page=43]]；[[PT-00-功能目錄#Ch22 — File and Session Management and Compatibility]] |
| 錄音檔、波形檔 | **Audio Files** | 錄製 Audio 時產生的媒體檔；可從中定義或使用 Clip，不能把 Clip 和原檔當同一層資料。 | 原書 p. 11；[[Pro_Tools_Reference_Guide_2023.3.pdf#page=43]]；[[PT-00-功能目錄#Ch17 — The Clips List]] |
| 音符資料、演奏事件 | **MIDI Data** | Session 內記錄或建立的 MIDI 資料直接存在 Session file；不會每錄一次就自動產生獨立 MIDI file。 | 原書 p. 11；[[Pro_Tools_Reference_Guide_2023.3.pdf#page=43]]；[[PT-00-功能目錄#Ch26 — MIDI Recording]] |
| 片段、區段、素材塊 | **Clip** | Audio、MIDI 或 Video 資料的一段，可短至音效，也可涵蓋整段演奏或完整檔案。 | 原書 p. 11；[[Pro_Tools_Reference_Guide_2023.3.pdf#page=43]]；[[PT-00-功能目錄#Ch17 — The Clips List]] |
| 片段組、整段一起搬 | **Clip Group** | 把多個 Clip 組成可共同操作的結構；可以跨 Track，也可能包含 Audio 與 MIDI。 | 原書 p. 12；[[Pro_Tools_Reference_Guide_2023.3.pdf#page=44]]；[[PT-00-功能目錄#Ch42 — Clip Loops and Groups]] |
| 版本、備選演奏、排列 | **Playlist** | Track 上 Clip 的排列；理解時要再區分 Edit Playlist 與 Automation Playlist。 | 原書 p. 12；[[Pro_Tools_Reference_Guide_2023.3.pdf#page=44]]；[[PT-00-功能目錄#Ch33 — Playlists]] |
| 剪輯版本、替代 Take | **Edit Playlist** | 告訴系統依什麼順序播放哪些 Clip；同一 Track 可有替代版本，用來比較演奏與編輯。 | 原書 p. 12；[[Pro_Tools_Reference_Guide_2023.3.pdf#page=44]]；[[PT-00-功能目錄#Ch33 — Playlists]] |
| 參數隨時間變化的資料 | **Automation Playlist** | 記錄 Volume、Pan、Mute 或已啟用參數等 Automation 的資料；與排列演奏 Clip 的 Edit Playlist 分開。 | 原書 p. 12；[[Pro_Tools_Reference_Guide_2023.3.pdf#page=44]]；[[PT-00-功能目錄#Ch53 — Automation]] |
| 雲端工程、協作工程 | **Project** | 2023.3 文件的 cloud-enabled 製作與協作容器，涉及本機 cache 與當時雲端服務；不要推定現行服務狀態。 | 原書 p. 15；[[Pro_Tools_Reference_Guide_2023.3.pdf#page=47]]；[[PT-00-功能目錄#Ch20 — Track Collaboration]] |

## Track 與控制

| 中文查找詞 | 英文名稱 | 用自己的話理解 | 原文與延伸 |
|---|---|---|---|
| 軌道、軌 | **Track** | 承載與編輯資料、或提供訊號路由／控制的工作單位；用途由 Track Type 決定。 | 原書 p. 9；[[Pro_Tools_Reference_Guide_2023.3.pdf#page=41]]；[[PT-00-功能目錄#Ch13 — Tracks]] |
| 聲道、通道 | **Channel** | 原書可能指硬體 I/O Channel、Mix Window 的 Channel Strip，或 MIDI Channel；看到這個字要先判斷上下文。 | 原書 p. 13；[[Pro_Tools_Reference_Guide_2023.3.pdf#page=45]]；[[PT-00-功能目錄#Ch02 — Pro Tools Concepts]] |
| 混音條、每軌控制區 | **Channel Strip** | Mix Window 中對應 Track 的控制區；Audio Fader 與 MIDI Fader 控制的對象並不相同。 | 原書 p. 13；[[Pro_Tools_Reference_Guide_2023.3.pdf#page=45]]；[[PT-00-功能目錄#Ch12 — Pro Tools Main Windows]] |
| 播放資源、音訊串流數 | **Voice** | 用於 Audio 路徑的離散串流資源；通常每個 Audio Channel 佔一個，但 Punch 與特定 HDX 路徑等會有額外需求。 | 原書 p. 10；[[Pro_Tools_Reference_Guide_2023.3.pdf#page=42]]；[[PT-00-功能目錄#Ch05 — Pro Tools Systems]] |
| 錄音軌、音訊軌 | **Audio Track** | 可從磁碟播放、錄到磁碟，並依錄音／TrackInput 狀態監聽 Input 的 Track。 | 原書 p. 1096；[[Pro_Tools_Reference_Guide_2023.3.pdf#page=1128]]；[[PT-00-功能目錄#Ch13 — Tracks]] |
| 回送軌、效果軌、群組音訊處理 | **Auxiliary Input Track** | Input 來自 Bus 或硬體，用於 Submix、Effects Return、外部音源監聽等；與從磁碟播放 Clip 的 Audio Track 不同。 | 原書 p. 1097；[[Pro_Tools_Reference_Guide_2023.3.pdf#page=1129]]；[[PT-00-功能目錄#Ch50 — Basic Mixing]] |
| 總推桿、主輸出控制 | **Master Fader Track** | 控制指定 Output 或 Bus Path 的整體電平；其 Inserts 為 post-fader，和 Audio／Auxiliary Input 不同。 | 原書 p. 1098；[[Pro_Tools_Reference_Guide_2023.3.pdf#page=1130]]；[[PT-00-功能目錄#Ch50 — Basic Mixing]] |
| 上層控制、一起調電平 | **VCA Master Track** | 控制所指派 Mix Group 的控制值；自身不傳遞 Audio 或 MIDI，所以不能拿來當效果回送。 | 原書 p. 1096；[[Pro_Tools_Reference_Guide_2023.3.pdf#page=1128]]；[[PT-00-功能目錄#Ch50 — Basic Mixing]] |
| MIDI 軌、外部樂器控制 | **MIDI Track** | 編輯與路由 MIDI data；資料可送往外部 MIDI device 或適當的 Instrument Plug-In 路徑。 | 原書 p. 14；[[Pro_Tools_Reference_Guide_2023.3.pdf#page=46]]；[[PT-00-功能目錄#Ch13 — Tracks]] |
| 虛擬樂器軌 | **Instrument Track** | 結合 MIDI 路由與樂器聲音路徑，常用來驅動 Instrument Plug-In 並安排其 Audio 輸出。 | 原書 p. 14；[[Pro_Tools_Reference_Guide_2023.3.pdf#page=46]]；[[PT-00-功能目錄#Ch13 — Tracks]] |
| 整理資料夾 | **Folder Track** | 用於組織 Track；要進一步區分整理用途和參與路由的 Folder 類型。 | 原書 p. 10；[[Pro_Tools_Reference_Guide_2023.3.pdf#page=42]]；[[PT-00-功能目錄#Ch14 — Folder Tracks]] |
| 資料夾群組處理 | **Routing Folder** | 提供與 Auxiliary Input 相同的訊號路由選項，並結合 Folder 的組織方式。 | 原書 p. 1097；[[Pro_Tools_Reference_Guide_2023.3.pdf#page=1129]]；[[PT-00-功能目錄#Ch14 — Folder Tracks]] |
| 多軌一起操作、群組 | **Group** | 讓群組內指定控制／編輯行為聯動；Group 本身不代表把 Audio 送進共同 Bus。 | 原書 p. 15；[[Pro_Tools_Reference_Guide_2023.3.pdf#page=47]]；[[PT-00-功能目錄#Ch16 — Grouping Tracks]] |

## 訊號路由

| 中文查找詞 | 英文名稱 | 用自己的話理解 | 原文與延伸 |
|---|---|---|---|
| 接線、訊號走向 | **Signal Routing** | 決定訊號從哪裡進入、經過哪些處理、到哪裡輸出；先把路由看清楚，再判斷是否需要處理。 | 原書 p. 14；[[Pro_Tools_Reference_Guide_2023.3.pdf#page=46]]；[[PT-00-功能目錄#Ch06 — I/O Setup]] |
| 路徑、選單裡的輸入輸出名稱 | **Path** | Pro Tools 的各種路由選項，包含 Inputs、Outputs、Busses、Inserts；可命名並在對應選單中使用。 | 原書 p. 15；[[Pro_Tools_Reference_Guide_2023.3.pdf#page=47]]；[[PT-00-功能目錄#Ch06 — I/O Setup]] |
| 內部匯流、群組訊號目的地 | **Bus** | 讓 Track 之間在軟體內交換或匯總訊號的路由；Bus 是路徑，Auxiliary Input 是能接收並處理的 Track。 | 原書 p. 14；[[Pro_Tools_Reference_Guide_2023.3.pdf#page=46]]；[[PT-00-功能目錄#Ch06 — I/O Setup]] |
| 額外送出、平行效果 | **Send** | 把 Track 的 Audio 另外送往硬體 Output 或內部 Bus；和主 Output assignment 的用途要分清楚。 | 原書 p. 14；[[Pro_Tools_Reference_Guide_2023.3.pdf#page=46]]；[[PT-00-功能目錄#Ch50 — Basic Mixing]] |
| 串效果、插入處理 | **Insert** | Track／路徑上的 Plug-In 或外部硬體處理位置；實際前後順序依 Track Type 而不同。 | 原書 p. 14；[[Pro_Tools_Reference_Guide_2023.3.pdf#page=46]]；[[PT-00-功能目錄#Ch51 — Plug-In and Hardware Inserts]] |
| 外接 Compressor、硬體效果回路 | **Hardware Insert** | 透過 Audio Interface 的 Output／Input 形成外部處理回路；需要正確的硬體與軟體路徑對應。 | 原書 p. 14；[[Pro_Tools_Reference_Guide_2023.3.pdf#page=46]]；[[PT-00-功能目錄#Ch51 — Plug-In and Hardware Inserts]] |
| 效果返回、回送 | **Effects Return** | 接收效果處理路徑回來的聲音；常用 Auxiliary Input 作為接收與控制位置。 | 原書 p. 1097；[[Pro_Tools_Reference_Guide_2023.3.pdf#page=1129]]；[[PT-00-功能目錄#Ch50 — Basic Mixing]] |
| 小混音、分組混音 | **Submix** | 把多條訊號匯集到共同控制／處理位置；例如多條 Audio Track 匯到一條 Auxiliary Input。 | 原書 p. 14；[[Pro_Tools_Reference_Guide_2023.3.pdf#page=46]]；[[PT-00-功能目錄#Ch50 — Basic Mixing]] |
| 推桿之前的處理 | **Pre-Fader Insert** | Audio／Auxiliary Input 的 Inserts 位於 Fader 前；後段 Fader 與前段處理的關係，要沿 Signal Flow 看。 | 原書 p. 1096；[[Pro_Tools_Reference_Guide_2023.3.pdf#page=1128]]；[[PT-00-功能目錄#Ch50 — Basic Mixing]] |
| 推桿之後的處理 | **Post-Fader Insert** | Master Fader 的 Inserts 位於 Fader 後，改 Fader 會改變進入其 Inserts 的電平。 | 原書 p. 1098；[[Pro_Tools_Reference_Guide_2023.3.pdf#page=1130]]；[[PT-00-功能目錄#Ch50 — Basic Mixing]] |

## 時間與處理

| 中文查找詞 | 英文名稱 | 用自己的話理解 | 原文與延伸 |
|---|---|---|---|
| 固定秒數、位置不跟 Tempo 動 | **Sample-Based Time** | 位置固定在 Sample Timeline；Tempo 改變時，素材仍留在相同 Sample 位置。 | 原書 p. 16；[[Pro_Tools_Reference_Guide_2023.3.pdf#page=48]]；[[PT-00-功能目錄#Ch02 — Pro Tools Concepts]] |
| 固定小節拍點、跟 Tempo 移動 | **Tick-Based Time** | 位置依 Bars／Beats；Tempo 改變時對應的 Sample 位置會變，但 Audio 是否改長度還要看 Elastic Audio。 | 原書 p. 16；[[Pro_Tools_Reference_Guide_2023.3.pdf#page=48]]；[[PT-00-功能目錄#Ch02 — Pro Tools Concepts]] |
| 拉時間、變速對拍 | **Elastic Audio** | 提供 Audio 的 Time Compression／Expansion 與相關分析／Warp 工作流程；單純設成 Tick-Based 不等於已做時間拉伸。 | 原書 p. 16；[[Pro_Tools_Reference_Guide_2023.3.pdf#page=48]]；[[PT-00-功能目錄#Ch45 — Elastic Audio]] |
| 把 Track 處理做成新軌 | **Commit Tracks** | 將指定來源的處理結果 Render 到新 Track，並依 Commit dialog 決定其他資料與來源 Track 的處置。 | 原書 p. 1047；[[Pro_Tools_Reference_Guide_2023.3.pdf#page=1079]]；[[PT-00-功能目錄#Ch47 — Committing, Freezing, and Bouncing Tracks]] |
| 凍結、減少即時運算 | **Track Freeze** | 以 Render 結果暫代部分或全部 Track 處理，減少即時負擔；要修改受限制的資料時先 Unfreeze。 | 原書 p. 1052；[[Pro_Tools_Reference_Guide_2023.3.pdf#page=1084]]；[[PT-00-功能目錄#Ch47 — Committing, Freezing, and Bouncing Tracks]] |
| 只凍結前面幾顆效果 | **Freeze Up To This Insert** | 把處理 Freeze 到指定 Insert，讓後面的未凍結 Inserts 保留可調整空間。 | 原書 p. 1054；[[Pro_Tools_Reference_Guide_2023.3.pdf#page=1086]]；[[PT-00-功能目錄#Ch47 — Committing, Freezing, and Bouncing Tracks]] |
| 輸出個別處理後 Track | **Bounce Track** | 把選定 Track 的結果輸出成 Audio file，省去為個別 Track 輸出而另建 Bus Recording 路由的工作。 | 原書 p. 1055；[[Pro_Tools_Reference_Guide_2023.3.pdf#page=1087]]；[[PT-00-功能目錄#Ch47 — Committing, Freezing, and Bouncing Tracks]] |
| 各軌處理延遲對齊 | **Delay Compensation** | 補償 Plug-In、Mixer Routing 等路徑延遲，維持 Track 間時間對齊；不是把所有錄音監聽延遲變成零。 | 原書 p. 1136；[[Pro_Tools_Reference_Guide_2023.3.pdf#page=1168]]；[[PT-00-功能目錄#Ch50 — Basic Mixing]] |
| 整套 Mixer 需要對齊的延遲 | **System Delay** | 原書以最大 Track 報告延遲加上額外 Mixer Routing 延遲說明；要看完整系統值，不能只看單軌 Insert 數字。 | 原書 p. 1137；[[Pro_Tools_Reference_Guide_2023.3.pdf#page=1169]]；[[PT-00-功能目錄#Ch50 — Basic Mixing]] |

## 最容易混淆的四組概念

| 概念組合 | 差別抓哪裡 | 進一步查找 |
|---|---|---|
| Session File／Media Files | 一個保存製作結構，另一個保存外部媒體 | [[#資料與編排]] |
| Track／Channel／Voice | 一個是工作單位，一個依上下文指聲道／控制條，一個是 Audio 串流資源 | [[#Track 與控制]] |
| Group／Bus／VCA Master | 操作聯動、訊號路徑與上層控制是三件事 | [[#Track 與控制]]、[[#訊號路由]] |
| Tick-Based／Elastic Audio | 前者決定時間座標，後者提供 Audio 時間處理 | [[#時間與處理]] |

> [!abstract] Takeaway
> 看到陌生名詞時，先問它是「資料」「工作單位」「路徑」「控制」還是「時間與處理」。同一個中文口語可能對應不同功能，保留英文名稱能減少溝通與查找歧義。
