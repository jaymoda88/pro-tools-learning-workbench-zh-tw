# 版本與原文疑義 — 遇到矛盾時怎麼讀

> 手冊是操作依據，但同一份文件也可能有殘留舊敘述或筆誤；遇到矛盾，要保留可追溯的頁碼。

這裡整理的是**本次閱讀發現的疑義**，不是 Avid 發布的正式 Errata。涉及實際軟體上限的地方，僅指出文件不一致，不把推測當成已經實測的結論。

| 資訊類型 | 本套筆記怎麼處理 | 你讀的時候怎麼判斷 |

| 2023.3 明確列出的功能與流程 | 依原書解說並附頁碼 | 按對應 software tier／hardware 條件閱讀 |

## 1. Ch11：24-bit Audio 的空間比較疑似筆誤

原書 p. 173（PDF p. 205）在 24-Bit 小節把 24-bit 與 16-bit 的檔案空間關係寫反。這可直接用未壓縮 PCM 的基本資料量檢查：

$$
\text{Audio payload bytes}=f_s\times T\times C\times\frac{B}{8}
$$

其中 $f_s$ 是 Sample Rate、$T$ 是秒數、$C$ 是 Channel 數、$B$ 是每個 Sample 的 Bit Depth。這是資料量概念的補充公式，**不是照錄原書公式**；實際檔案還有 Header／Metadata 等開銷。

在其他條件相同、使用對應位深的未壓縮 PCM Sample 儲存時：

$$
\frac{\text{24-bit payload}}{\text{16-bit payload}}=\frac{24}{16}=1.5
$$

因此，24-bit 的 Audio payload 是 16-bit 的 **1.5 倍**，而不是三分之一。旁邊 32-bit 對 24-bit 的比例則是 $32/24=4/3$；兩個比較不要混在一起。

| 比較條件 | 正確的 Audio payload 比例 | 適用前提 |
|---|---|---|
| 24-bit ÷ 16-bit | 1.5 倍 | Sample Rate、時長、Channel 相同；未壓縮 PCM |
| 32-bit ÷ 24-bit | 約 1.333 倍 | 相同條件；以每個 Sample 的儲存位元計算 |

原文定位：[[Pro_Tools_Reference_Guide_2023.3.pdf#page=205]]。延伸見 [[PT-00-功能目錄#Ch11 — Sessions and Projects]]。

> [!tip] 實務連結
> 估算錄音媒體容量時，先用 Sample Rate、Channel、時長與 Bit Depth 算 Audio payload，再為多次 Take、備份與檔案額外資訊留空間。不要直接把工程檔大小當成所有媒體的大小。

## 3. Ch54：多來源 Bounce 的 24 與 16 不一致

原書 p. 1257（PDF p. 1289）的 Multiple Mix Sources 小節，在說明段與操作步驟寫了不同數量。

| 同頁位置 | 文件列出的數量 | 閱讀方式 |
|---|---|---|
| 功能說明 | Ultimate／Studio 可同時 Bounce 最多 24 個 Sources | 保留原文的 software tier 條件 |
| 新增來源的操作步驟 | 以「+」新增 Mix Source 時寫最多 16 個 | 和說明段並列記錄，不擅自消除矛盾 |

此處**不直接判定哪個數字才是實際版本上限**。讀懂 Multiple Mix Sources 的選擇與輸出流程後，實際工作再核對你的 software tier、版本與 Bounce Mix dialog。

原文定位：[[Pro_Tools_Reference_Guide_2023.3.pdf#page=1289]]。延伸見 [[PT-00-功能目錄#Ch54 — Mixdown]]。

## 4. 為什麼快捷鍵也必須標版本與條件

本套 [[PT-00-Mac快捷鍵]] 以 Avid 官方 **Pro Tools Shortcuts Guide 2023.3** 作主要來源，與 Reference Guide 對齊。快捷鍵是否執行，還取決於視窗與輸入焦點、Commands Keyboard Focus、Numeric Keypad Mode，以及是否曾自訂指派。

| 看起來像同一件事 | 實際需要分清楚 |
|---|---|
| 鍵盤上都是數字 | 主鍵盤數字列與 Numeric Keypad 可能不同 |
| 都叫 Control | Mac Control（⌃）和 Command（⌘）是不同的鍵 |
| 都是單鍵 | 正在輸入文字與 Commands Keyboard Focus 的行為不同 |
| 同一組按鍵 | 不同 Context 或自訂 Preset 可能對應不同指令 |

官方來源：[Pro Tools Shortcuts Guide 2023.3](https://resources.avid.com/SupportFiles/PT/Pro_Tools_Shortcuts_2023.3.pdf)。需要查新版本時，應另外核對該版本的官方文件，避免把多個年代的表混成一份。

## 5. Ch33：Playlist 按鍵有內文與總表差異

Reference Guide 的操作內文與章末快捷鍵表，對相近的 Playlist 動作列出不同按鍵。這些描述可能涉及上下文差異或原稿誤植，不能只截取其中一行就視為所有情況都適用。

| 動作／上下文 | Reference Guide 內文 | Reference 章末表與 Shortcuts Guide |
|---|---|---|
| Copy Selection 到新的 Playlist／Target Playlist | p. 739（PDF 771）列 Mac `⌃⇧←` | Reference p. 757、Shortcuts p. 36／52 列 `⌥⇧↓` |
| Move Selection 到新的 Playlist | p. 741（PDF 773）列 Mac `⌃⇧N` | Reference p. 757、Shortcuts p. 36／52 列 `⌥⇧N` |
| 把同名 Playlist 設為所有 Audio Track 的 Target | p. 753（PDF 785）內文列 `⌥-click` Target | Reference p. 758、Shortcuts p. 37 列 `⇧-click` Target |

本套 [[PT-00-Mac快捷鍵]] 的速查列，以官方 **Shortcuts Guide 2023.3 內互相一致的表格**作依據，並標明 Playlist lane 與 Track selection 等條件。若你的選單命令或自訂指派不同，應先核對 Keyboard Shortcuts window；需要確保執行哪個動作時，可從相同 Context 的選單進入，不猜 modifier。

來源：Reference [[Pro_Tools_Reference_Guide_2023.3.pdf#page=771]]、[[Pro_Tools_Reference_Guide_2023.3.pdf#page=773]]、[[Pro_Tools_Reference_Guide_2023.3.pdf#page=785]]、[[Pro_Tools_Reference_Guide_2023.3.pdf#page=789]]、[[Pro_Tools_Reference_Guide_2023.3.pdf#page=790]]；Shortcuts [[Pro_Tools_Shortcuts_2023.3.pdf#page=41]]、[[Pro_Tools_Shortcuts_2023.3.pdf#page=42]]、[[Pro_Tools_Shortcuts_2023.3.pdf#page=57]]。Shortcuts 的正文頁碼與 PDF 頁序相差 5 頁，不是 Reference 的 32 頁。
