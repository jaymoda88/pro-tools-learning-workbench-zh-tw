# 工作流程導航 — 從手上的工作找到該讀的章

> 先看你現在要完成什麼，再沿著必要步驟找功能；不用從第 1 頁讀到最後一頁才開始做音樂。

## 第一次建立可工作的 Session

新手最容易同時遇到三個陌生層級：Session 裡存了什麼、Track 是拿來做什麼、訊號怎麼進出。先建立這三個觀念，再背工具名稱會容易得多。

| 順序 | 先回答的問題 | 應讀章節 | 到這裡你應該能做的事 |
|---|---|---|---|
| 1 | Session 與媒體、Audio 與 MIDI 差在哪？ | [[PT-00-功能目錄#Ch02 — Pro Tools Concepts]] | 分清楚不同資料，不把工程檔當成所有錄音檔 |
| 2 | 這次工作要如何建立工程？ | [[PT-00-功能目錄#Ch11 — Sessions and Projects]] | 理解建立與開啟 Session／Project 的設定 |
| 3 | 電腦要透過哪個 Playback Engine 工作？ | [[PT-00-功能目錄#Ch07 — System Setup]] | 找到音訊引擎與系統設定入口 |
| 4 | Input、Bus、Output 怎麼對應？ | [[PT-00-功能目錄#Ch06 — I/O Setup]] | 理解軟體路徑與硬體對應 |
| 5 | Edit Window、Mix Window 與 Track 怎麼分工？ | [[PT-00-功能目錄#Ch12 — Pro Tools Main Windows]] | 找到編輯與混音的主要控制 |
| 6 | 該新增哪種 Track？ | [[PT-00-功能目錄#Ch13 — Tracks]] | 按資料與訊號用途選 Track |

> [!tip] 實務連結
> 不必在第一天就讀完所有硬體系統規格。先讓一條 Audio Track 有正確 Input 與 Output，再逐步增加 MIDI、Auxiliary Input 或 Folder Track；每多一層，都能說出它在訊號路徑裡的用途。

## 準備一場錄音

錄不到聲音時，Record button 只是其中一個檢查點。音源接入、Track 指派、Record Enable、監聽模式、Playback Engine 與儲存位置，都有各自的工作。

| 步驟 | 查什麼 | 功能與章節 | 原書定位 |
|---|---|---|---|
| 1 | 音源接到哪裡？ | Connecting a Sound Source；[[PT-00-功能目錄#Ch24 — Record Setup]] | 原書 p. 538；[[Pro_Tools_Reference_Guide_2023.3.pdf#page=570]] |
| 2 | Track 的 Input／Output 對嗎？ | Assigning Hardware I/O on a Track；[[PT-00-功能目錄#Ch24 — Record Setup]] | 原書 p. 547；[[Pro_Tools_Reference_Guide_2023.3.pdf#page=579]] |
| 3 | 哪些 Track 準備錄？ | Record Enabling Tracks；[[PT-00-功能目錄#Ch24 — Record Setup]] | 原書 p. 548；[[Pro_Tools_Reference_Guide_2023.3.pdf#page=580]] |
| 4 | 現在監聽到的是什麼？ | Record Input Monitoring／Monitoring Latency；[[PT-00-功能目錄#Ch24 — Record Setup]] | 原書 p. 553；[[Pro_Tools_Reference_Guide_2023.3.pdf#page=585]] |
| 5 | 要錄整段、Loop 還是補錄？ | Audio Recording／Punch Recording Modes；[[PT-00-功能目錄#Ch25 — Audio Recording]] | 原書 p. 559；[[Pro_Tools_Reference_Guide_2023.3.pdf#page=591]] |
| 6 | 如何留下多次 Take？ | Recording Additional Takes／Alternate Takes；[[PT-00-功能目錄#Ch25 — Audio Recording]] | 原書 p. 568；[[Pro_Tools_Reference_Guide_2023.3.pdf#page=600]] |

> [!warning] 同一個症狀，可能是不同層級
> 「沒有聲音」要再細分：Meter 完全不動、Meter 有動但聽不到、Playback 聽得到但錄音時聽不到，查找起點會不同。先觀察，再依 [[#先定位問題層級]] 縮小範圍。

## 人聲與樂器 Comping

多錄幾次只是增加素材，Comping 才是把素材挑成表現一致的版本。把「挑演奏」「整理接縫」「調整音量」分開思考，會比一次全做更容易判斷。

| 階段 | 想解決的問題 | 功能／閱讀位置 | 檢查重點 |
|---|---|---|---|
| 保留 Take | 原始版本和工作版本怎麼管理？ | Playlists；[[PT-00-功能目錄#Ch33 — Playlists]] | 確認正在工作的 Playlist 與目標 Playlist |
| 挑選演奏 | 每一句到底要用哪個 Take？ | Track Compositing；[[PT-00-功能目錄#Ch33 — Playlists]] | 先判斷演奏，再處理接縫 |
| 整理剪接 | 換 Take 後接縫是否自然？ | Fades and Crossfades；[[PT-00-功能目錄#Ch32 — Fades and Crossfades]] | 接縫要聽過，不只看畫面 |
| 調整片段音量 | 句與句的進入電平是否合適？ | Clip Gain；[[PT-00-功能目錄#Ch44 — Clip Gain and Clip Effects]] | 和後段 Volume Automation 分開看 |
| 音準處理 | 需要哪些音高修整？ | Melodyne Editing；[[PT-00-功能目錄#Ch46 — Melodyne Editing and Audio to MIDI]] | 先辨識要保留的演奏細節 |
| 整段動態 | 音量如何隨歌曲前進？ | Automation；[[PT-00-功能目錄#Ch53 — Automation]] | 分清楚局部 Clip 處理與整軌控制 |

這是學習順序，不是固定處理鏈。某些工作需要先修音再 Comp，有些需要先討論演奏；回到 Ch33、Ch44 與 Ch53，弄清楚每個功能改動的對象，才不會改錯層級。

## 修節奏與調整時間

先問自己「是音樂時間有問題，還是格線沒有跟上演奏？」再選工具。原書把 Tempo、Beat Detective、Elastic Audio 分在不同章節，因為它們處理的對象與工作方式不同。

| 你要研究的問題 | 優先功能 | 閱讀位置 | 延伸比較 |
|---|---|---|---|
| Tempo、Meter 與時間基準怎麼設定？ | Time, Tempo, Meter, Key, and Chords | [[PT-00-功能目錄#Ch39 — Time, Tempo, Meter, Key, and Chords]] | 先理解格線與時間座標 |
| 從節奏素材辨識節拍與切點 | Beat Detective | [[PT-00-功能目錄#Ch34 — Beat Detective]] | 分析、Trigger、Separate、Conform、Smoothing 各自做什麼 |
| 把 Audio 的時間結構拉伸到目標 | Elastic Audio | [[PT-00-功能目錄#Ch45 — Elastic Audio]] | Analysis、Warp、演算法與處理模式 |
| MIDI 事件要如何移動或批次修整？ | MIDI Editing／Event Operations | [[PT-00-功能目錄#Ch35 — MIDI Editing]] | MIDI 事件操作和 Audio 處理分開看 |
| 剪開後接縫要怎麼處理？ | Fades and Crossfades | [[PT-00-功能目錄#Ch32 — Fades and Crossfades]] | 節奏對齊之後仍要聽過接縫 |

> [!important] 準確不是唯一目標
> 原書功能能告訴你怎麼分析、移動與處理；要保留多少律動，仍要由音樂決定。工具的作用範圍、各麥的相對關係與處理後聲音都要檢查。

## 處理資源與可回頭修改

「想減少運算」「想把一段效果寫成檔案」「要交付一條處理後的 Track」是不同目的。先按目的找功能，再閱讀適用條件，不要只因為結果都像 Audio file 就混在一起。

| 目的 | 比較哪幾項 | 查找位置 |
|---|---|---|
| 把某段 Audio 做離線處理 | AudioSuite Processing | [[PT-00-功能目錄#Ch43 — AudioSuite Processing]] |
| 在 Track 層級固定處理或減少即時負擔 | Commit Tracks／Track Freeze／Bounce Track | [[PT-00-功能目錄#Ch47 — Committing, Freezing, and Bouncing Tracks]] |
| 確認哪些即時處理耗用資源 | Playback Engine／System Usage | [[PT-00-功能目錄#Ch07 — System Setup]] |
| 判斷硬體支援的 DSP 工作模式 | DSP Mode | [[PT-00-功能目錄#Ch52 — DSP Mode]] |
| 完成整個混音輸出 | Bounce Mix／Mixdown | [[PT-00-功能目錄#Ch54 — Mixdown]] |

## 先定位問題層級

下面是查閱導航，不是對所有故障都通用的修復處方。先描述你**看到了什麼、聽到了什麼**，再決定應翻哪個設定。

| 觀察到的現象 | 優先查找主題 | 查哪裡 |
|---|---|---|
| Input Meter 不動 | 音源接線、Track Input、硬體 I/O | [[PT-00-功能目錄#Ch24 — Record Setup]] |
| Meter 有動但沒有輸出 | Output、Bus、監聽路由 | [[PT-00-功能目錄#Ch06 — I/O Setup]] |
| 錄音時有明顯延遲 | Monitoring Latency／Playback Engine | [[PT-00-功能目錄#Ch24 — Record Setup]] |
| 單鍵編輯沒反應 | Commands Keyboard Focus／輸入焦點 | [[PT-00-功能目錄#Ch03 — Keyboard and Mouse Shortcuts]] |
| 數字鍵行為和想像不同 | Numeric Keypad Mode | [[PT-00-功能目錄#Ch03 — Keyboard and Mouse Shortcuts]] |
| 按鍵相同卻做出不同動作 | Keyboard Shortcuts Preset／Custom Assignment | [[PT-00-功能目錄#Ch03 — Keyboard and Mouse Shortcuts]] |
| Tempo 改變後素材的位置不符預期 | Sample-Based／Tick-Based Time | [[PT-00-功能目錄#Ch02 — Pro Tools Concepts]] |
| 操作牽動其他 Track | Group 與共同控制 | [[PT-00-功能目錄#Ch16 — Grouping Tracks]] |
| Fader 被拉回或一直覆寫 | Automation Mode／Automation Playlist | [[PT-00-功能目錄#Ch53 — Automation]] |
| 搬移 Session 後媒體不完整 | Audio File Management／Compatibility | [[PT-00-功能目錄#Ch22 — File and Session Management and Compatibility]] |
| 處理負載變高 | System Usage／Playback Engine | [[PT-00-功能目錄#Ch07 — System Setup]] |

> [!abstract] Takeaway
> 先辨識問題落在資料、時間、訊號路由、控制或系統哪一層，再挑功能。你需要的是一條能帶你走到答案的路線；真正要按哪個選項，回到相應教學篇與原書小節查。
