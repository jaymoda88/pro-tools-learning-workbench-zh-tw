# 2026 錄音與編輯實作

> 先確保素材可找回，再把畫面、文字與音訊切分成方便檢查的單位，編輯速度才不會以可靠性為代價。

這頁以 Avid 2026.4 文件為操作依據，補充原有 **2023.3** 章節，不表示所有舊版都有這些功能。選單與鍵盤自訂設定可能不同；實作前先複製一份練習 Session，避免直接改動唯一的正式工程。

## 1｜匯入錄音：確認工程到底引用哪個檔案

Audio Clip 是指向音訊資料的編輯物件；看到波形並不代表原檔已經複製進 Session。從外接碟或下載資料夾直接加入檔案時，之後移動來源可能讓工程找不到媒體。先讀 [[PT-Ch28-編輯前先分清Clip與資料]]，再用以下方式決定匯入。

| 操作 | 資料在哪裡 | 適合的判斷 |
|---|---|---|
| Add | 保留原位置，Session 引用原檔 | 來源位置由你長期管理，且檔案條件適用時 |
| Copy | 在 Session 的 Audio Files 建立副本，保留原檔 | 要把媒體隨工程整理，且不需轉換時 |
| Convert | 轉為 Session 格式、sample rate 與 bit depth，寫入 Audio Files | 匯入時需要符合工程格式 |

1. 在新 Session 選 **File > Import > Audio**，檢查來源檔的格式與 sample rate，再依需求選擇 Copy 或 Convert。
2. 匯入後確認 Track 上有預期的 Clip；另在檔案管理器確認 Session 的 Audio Files 有預期副本。
3. 播放開頭、中間與結尾，確認聲音、速度與音高合理，再儲存 Session。

> [!warning] Sample rate 不是只改標籤
> 文件指出不同 sample rate 的檔案若不轉換而直接加入，播放速度與音高會不同。不要只因畫面出現波形就認定匯入成功。

> [!tip] 實務連結
> 收到配音或採訪素材時，記下原始檔位置與採用的匯入方式；交接還需要檢查其他相依媒體，而非僅看這一個資料夾。參見 [[PT-Ch21a-Audio與MIDI匯入匯出]]。來源：[Reference Guide 2026.4，PDF 737–738](https://resources.avid.com/SupportFiles/PT/Pro_Tools_Reference_Guide_2026.4.pdf#page=737)。

## 2｜大型工程固定參照 Track

2026.4 的 **Track Pinning** 在 Edit window 上方建立原 Track 的 alias：它不是另一份錄音。兩處共用資料，因此任一處的編輯會同步；但 Track height、view 與 automation lanes 可以分別設定，讓固定區當成精簡參照，原位置保留完整編輯視圖。

1. 在 Edit window 對要參照的 Track name 按右鍵，選 **Pin**。例如固定主唱，再向下捲動到和聲 Track。
2. 在固定區選擇適合的 view，拖曳固定區下緣調整空間；在原 Track 做一個可復原的小編輯，確認 alias 同步。
3. 要返回原位置，右鍵固定 Track name 選 **Scroll into View**；不再需要時選 **Unpin**。

**檢核：**捲動其他 Tracks 時固定 Track 仍在上方；同時能說明固定區和原 Track 共享的是資料，而不是獨立備份。

> [!warning] Replace 的範圍
> **Pin and Replace** 會取代固定區內全部既有 Tracks，不是只換掉一條。固定 Folder 只顯示平面 Folder Track，內部成員仍需回原 Folder 查看；固定與原 Track 的 show/hide 狀態共用。

> [!tip] 實務連結
> 比較主唱與多軌和聲、或剪對白時對照參考 Track，都能減少垂直捲動。Track Pinning 的 2026.4 功能說明適用各 tiers；先確認安裝版本。參見 [[PT-Ch13b-建立編輯與管理Track]] 與 [What's New 2026.4，PDF 10–14](https://resources.avid.com/SupportFiles/PT/Whats_New_in_Pro_Tools_2026.4.pdf#page=10)。

## 3｜用逐字資料切分對白，再聽聲音確認

逐字資料讓你按語句尋找素材；真正的剪接判斷仍要聽呼吸、尾音與上下文。2026.4 可在 Track 上對選取範圍依 Word、Sentence 或 Speaker 分割，並可跨多個已轉錄的 Clips 與 Tracks。

1. 先準備已完成轉錄的音訊 Clips；在 Timeline 選取要處理的範圍。
2. 右鍵所選 Clip，選 **Transcription > Separate Clip by Word、Sentence 或 Speaker**。整理訪談時可先依 Speaker，再視需求處理語句。
3. 播放每個切點附近，修正被切掉的尾音與不自然的停頓。若看不到文字，先確認 **View > Track Transcription Lane** 開啟，再右鍵 Track name 檢查 **Show Transcription Lane**；Track 至少要有一個帶逐字資料的 Clip 才會顯示 lane。

**檢核：**選一個切點，能同時用文字定位與聆聽確認其自然程度。Consolidate、AudioSuite render、Commit 與 Bounce Track 產生的新音訊會自動接收轉錄資料；這不等於轉錄內容已人工校對。

> [!warning] 方案限制
> 這些 Transcription 改進在 2026.4 文件中列為 **Studio 與 Ultimate** 功能。逐字資料會有辨識錯誤，尤其人名與重疊說話必須回聽。來源：[What's New 2026.4，PDF 18–20](https://resources.avid.com/SupportFiles/PT/Whats_New_in_Pro_Tools_2026.4.pdf#page=18)。

> [!tip] 實務連結
> 長訪談可先以 Speaker 建立候選片段，再以聽感決定是否保留完整句子。[[PT-Ch30-選取範圍與時間軸導航]] 的選取觀念仍然適用。

## 4｜把密集剪接整理成連續音檔

多次切分與 crossfade 讓 Session 易讀性與效能受到影響時，**Consolidate** 可把選取區域整理成連續音檔。它適合在確認剪接後減少片段數；但保留編輯前版本仍有價值，因為之後可能要改切點。

1. 先儲存另一個 Session 版本，播放並確認剪接與 fades。
2. 選取要整理的時間範圍，確認開頭、結尾及 Track。執行 **Consolidate Clip**；預設 Mac 為 **Option+Shift+3**，Windows 為 **Alt+Shift+3**。
3. 比較整理前後的起點、終點與聽感，確認新 Clip 覆蓋預期範圍。

> [!warning] 選取就是處理邊界
> 範圍太短可能漏掉尾音；一次跨多 Track 整理大量區域前，也要確認記憶體資源。若仍需彈性調整切點，可先保留未 Consolidate 的版本。

> [!tip] 實務連結
> 整理過的鼓組編輯較容易移交或管理，但不要為了畫面整齊而太早放棄可修改的剪接。來源：[Reference Guide 2026.4，PDF 1105](https://resources.avid.com/SupportFiles/PT/Pro_Tools_Reference_Guide_2026.4.pdf#page=1105)；[Shortcuts Guide 2026.4，PDF 54](https://resources.avid.com/SupportFiles/PT/Pro_Tools_Shortcuts_2026.4.pdf#page=54)。

> [!abstract] Takeaway
> 先確認媒體位置，再以 Pin 固定參照、用逐字資料加速定位，最後在聽過切點後才 Consolidate；每一步都留下能回查的依據。
